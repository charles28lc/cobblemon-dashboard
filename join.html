Cobblemon Server

How to join

Status Join Commands Controls

Server address

della-asm.tun.ply.gg

No port needed. The server is whitelisted, so you need to be added before you can get in (step 1).

You'll need

  • Minecraft: Java Edition on Windows, Mac or Linux. Bedrock, Xbox, PlayStation, Switch and phone versions can't join.
  • The free CurseForge app.

Version must match

Modpack
Cobblemon Official Modpack [Fabric]
Modpack version
1.8.1
Minecraft
1.21.1

Steps

  1. Get whitelisted. Send the host your Minecraft Java username (the name shown in the launcher, exact spelling).
  2. Install the modpack. In CurseForge, open Minecraft, search modpacks for Cobblemon Official Modpack [Fabric] by CobbledStudios, and click Install. Make sure it's version 1.8.1 (Minecraft 1.21.1), not the 1.20.1 one.
  3. Give it enough memory. CurseForge Settings → Minecraft → Java Settings → Allocated Memory: set it to 4–6 GB if your PC has 16 GB or more (the pack's minimum is about 3 GB).
  4. Launch it. Click Play on the modpack. The first launch takes a few minutes.
  5. Add the server. Multiplayer → Add Server → paste della-asm.tun.ply.gg into Server Address → Done.
  6. Join. Double-click the server. Your first time in, press M to pick your starter Pokémon.

If it doesn't work

"You are not whitelisted on this server"
You haven't been added yet, or the username was spelled differently. Message the host.
Errors about mods or versions
Your modpack version doesn't match. In CurseForge, switch the modpack to version 1.8.1.
"Can't connect" or "Timed out"
Check the Status page. If it says Offline, the server is off right now.
Low FPS or stuttering
Give Minecraft more memory (step 3), and close other heavy programs.
