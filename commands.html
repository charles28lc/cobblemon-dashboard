Commands everyone can use

Status Pokédex Join Commands Controls

Teleport

/tpa [player]
Ask to teleport to someone. Requests expire after 60 seconds.
/tpahere [player]
Ask someone to teleport to you.
/tpaccept · /tpdeny
Answer a request. Add a name to pick which one.
/tpcancel
Cancel a request you sent.
/spawn
Go to world spawn.
/back
Go back to where you were before your last teleport. Doesn't work after dying.
/trigger rtp
Random teleport to safe ground 500–3,000 blocks from spawn. Overworld only, 2-minute cooldown. (Plain /rtp is admin-only.)

Home 3 per player

/home set [name]
Save where you're standing as your home. The name is optional.
/home tp [name]
Teleport home.
/home list
List your homes.
/home delete [name]
Delete a home.

Chat

/msg [player] [message]
Private message. /w and /tell do the same.
/me [action]
Say something in third person.
/list
See who's online.
/help
List every command you're allowed to use.

Other

/afk
Mark yourself as away. Happens on its own after 15 minutes idle.
/gametime
Show the in-game time.
/wastebin
Open a trash bin to delete items.
/suicide
Respawn if you're stuck. You drop your items like a normal death.
/warp list · /warp tp [name]
Warps are set by the host.

Pokémon

Cobblemon is played through its own menus, not commands. The one player command is /abandonmultiteam, which leaves a multi-battle team.

Admin-only commands aren't listed. Checked against the server's mods and config.
